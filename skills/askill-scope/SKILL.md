# Agree on the work

Inspect the current behavior and affected area. Agree with the user on the desired outcome, exclusions, decisions that could change the result, and whether to split the work into multiple issues. Leave implementation details and exact acceptance checks to each issue's preflight.

Record the agreed drafts and scope of approval in `.askill/intakes/<intake-id>.json`. Do not publish issues at this stage.
