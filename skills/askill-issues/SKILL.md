# Register or link issues

Read existing issues at the configured destination to confirm the target and check for duplicates. Agreement on a draft is not permission to create a remote issue. Create only within the granted scope and record each actual ID and URL promptly so that resuming does not register it twice.

Normalize local issues, verified remote issues, and links to existing issues to the same input format. Do not include unregistered drafts in the confirmed set. Link tickets only when a destination and authorization exist.
