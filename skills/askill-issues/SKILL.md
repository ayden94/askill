# Register or link issues

설정된 이슈 목적지에서 기존 이슈를 읽어 중복과 대상을 확인한다. 합의한 초안과 원격 생성 권한은 별개다. 권한 안에서만 생성하며, 이미 생성된 것의 실제 ID·URL을 먼저 기록해 재개 시 중복 등록을 피한다.

로컬 이슈, 원격에서 확인한 이슈, 기존 이슈 연결을 같은 입력 형식으로 만들되, 미등록 초안은 확정 이슈 목록에 넣지 않는다. 티켓 연결은 설정과 권한이 있을 때만 한다.
