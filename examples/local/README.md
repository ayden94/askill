# Local-only example

These are illustrative inputs, not production validation fixtures or actual receipts.

- [`config.json`](config.json): local issue registration, no PR or ticket destination.
- [`issues.json`](issues.json): one registered local issue.
- [`lane.json`](lane.json): the planned issue set, no semantic dependencies or remote grants.
- [`preflight.json`](preflight.json): what to change, what to preserve, and how to verify it, without a project contract document.

The repeated-digit SHAs are illustrative placeholders, not real Git or issue identities. The engine requires the current digests returned by `plan`; these example records are not import-ready receipts. The example ends before implementation and makes no claims about checks, OCR, or reviewer outcomes.
